# Phase 6A — Backend / Website / Mobile Drift

Nguồn A: BE-REF router -> validator/controller -> service -> models/gates/tests. Nguồn B: website source READ ONLY, chỉ OBSERVED_IN_WEB_FRONTEND, không xác nhận server chấp nhận request. Nguồn C: mobile fixtures/models/schemas hiện tại, MOBILE_FIXTURE_ONLY. Không sửa implementation trong audit.
