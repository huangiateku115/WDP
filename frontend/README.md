# SelfStorage Shadcn UI

Rebuilt from the supplied Stitch HTML/screens using React + Vite + Tailwind + shadcn-style Radix components.

## Run

```bash
npm install
cp .env.example .env
npm run dev
```

Set `VITE_USE_MOCK=true` while backend APIs are not ready. Existing API modules are kept under `src/api` so real endpoints can replace mock behavior later.
