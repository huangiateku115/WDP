# MI-01 missing Facility Detail button — 2026-10-12

## A. Root cause

Reproduced on the real public page for **Ho Chi Minh Facility 3**, facility ID `6ac4561b9a1f0501dfd90243`.

The public response has `serviceTypes: ["SELF_STORAGE", "MANAGED_INVENTORY"]`, the correct PublicFacilityDetail route is registered once, and the map link is rendered. `Button` supports both asChild and the orange variant. The defect is **white text on a transparent background before hover**, not a missing conditional or route.

Evidence from the actual in-app browser before the color fix:

- Non-hover computed background: `rgba(0, 0, 0, 0)`.
- Computed text color: `rgb(255, 255, 255)`.
- `.experience-theme .bg-orange { background:#f28c28 }` in `src/layouts/experience.css` applies only to the portal/experience wrapper. Public Facility Detail is outside that wrapper.
- `bg-orange` has no configured DEFAULT Tailwind color in the current `tailwind.config.js`. Its default background is therefore absent on the public page.
- The valid `hover:bg-orange-600` class makes the otherwise invisible link appear when hovered, which explains why DOM existence/size checks alone missed the defect.

A separate environment mismatch was also observed: current WDP Vite PID 18744 listens on `::1:5173`; the open user tabs pointed to `127.0.0.1:5173` and showed old network-error states. They were navigated to the working `localhost:5173` origin. The old detail tab's ID resolves to Ha Noi Facility 02, not the reported Ho Chi Minh facility. An unrelated EXE project on 5174 was identified and left untouched. These findings do not replace the confirmed CSS root cause above.

## B. Minimal fix

In PublicFacilityDetail only:

- Give View Warehouse Map explicit existing-theme colors: `bg-[#F28C28] text-white hover:bg-[#DD781B]`.
- Wrap the existing two service-conditional links in `mt-5 flex flex-wrap gap-3`, with max-w-full buttons. Desktop buttons share a row; mobile wraps to separate rows.
- Preserve both original service checks, destinations, Button/Link components, public visibility and Self Storage behavior.

No shared Button, Tailwind configuration, API client, Backend, authentication, routing, animations or other-role workspace was changed.
