## SDK và lỗi

Lock của source pin `@payos/node 2.0.5` và đã cài đúng phiên bản trong fixture tạm. Bản package trên Render chưa biết. `defaultGateway` dùng object `{clientId, apiKey, checksumKey, logLevel:'off'}`. SDK `lib/client.js:47,66–97,227–282,284–332` mặc định `https://api-merchant.payos.vn`, timeout 60 s, nhận override `PAYOS_BASE_URL` và tùy chọn `PAYOS_PARTNER_CODE` qua env. WDP không truyền timeout riêng, dùng `paymentRequests.create(data,{maxRetries:0})`. SDK resource `lib/resources/v2/payment-requests/payment-requests.js:20–32` dùng POST `/v2/payment-requests` và GET cùng resource theo orderCode, ký create và kiểm chữ ký phản hồi nếu SDK nhận được chữ ký. Axios Website có timeout 15 s, nên browser có thể hết chờ trước provider/Backend. HTTP 503 có envelope và timeout không có response là hai quan sát khác nhau.

Lỗi HTTP có status và code. SDK cũng có thể từ chối HTTP 2xx nếu business code khác `00` hoặc thiếu data. Network/timeout throw class riêng, và parsing/chữ ký có thể fail sau khi provider nhận request. `classifyProviderCreateError:167–192` phân loại 401/403, 400/422, 429, timeout, network và SDK/unknown qua allowlist. Ví dụ HTTP 200 kèm business code sẽ không được xếp vào validation chỉ dựa trên status. Tại `:598–610,656–664`, cờ invoked là lời gọi gateway đã bắt đầu trong process, chưa chứng minh packet tới PayOS. ResponseReceived có thể dựa trên error metadata. PersistenceConfirmed yêu cầu write/readback, `false` không chứng minh write chưa xảy ra. Correlation ở `:147–148` là 16 ký tự đầu SHA-256 của `PAYOS_CHECKOUT:<paymentId>`. Log `:194–208` không chứa checkoutState trực tiếp, cần nối bằng record/timestamp. [PayOS Node SDK](https://payos.vn/docs/sdks/back-end/node/).

Tài liệu lịch sử `backend/docs/PAYOS_PROVIDER_CREATE_FAILED_DIAGNOSIS.md` mô tả log cũ và giả thuyết description 25 ký tự. Source `9149930:608` đã tạo 9 ký tự. Quan sát `PAYOS_LOCAL_PROBE_FAILURE` / `SDK_ERROR` do người dùng cung cấp chưa có correlation/timestamp ghép với incident này. Không chạy probe, không đọc credential và không dùng tài liệu cũ để xác nhận nguyên nhân Render.
